You know that if you multiply two binomials you get a answer that is in ax^2+bx+c form, but there is a simpler way to solve for x *if your answer equals to 0*.  
## How  To Use It

![alt](https://cdn.virtualnerd.com/thumbnails/Alg1_7_1_12-diagram_thumb-lg.png)

$$
Q: (2x−1)(4x−3)=0
First split the equations into two.
(2x-1)=0
(4x-3)=0
Then solve normally.
2x−1=0⇒x= 1/2 or 0.50

4x-3=0⇒x = 3/4 or 0.75
​
$$
So, step by step, here is what to do. 
<div class="thi-columns" markdown="1">
- Split Equation into two
- Solve Normally
- Check!
</div>

## Why 0?
The Zero **Product** Property states that if two numbers product is 0 then one of the factors is 0. Another way of writing this is:

*If a⋅b=0, then either a=0 or b=0*
Note that this property doesn't work for sums! When the product equals zero, you can conclude that one or more of the factors must be zero, but when the sum equals zero, you just need to solve the equation directly (i.e., isolate the variable).
$$
SUM EQUALS ZERO: 4x-3=0

FACTORS EQUALS ZERO: X*0
$$

        function checkAnswer(question, selectedAnswer) {
            const correctAnswers = {
                q1: "a",
                q2: "a",
                q3: "a",
                q4: "c",
                q5: "a"
            };

            const explanations = {
                q1: "For the equation (2x - 1)(4x - 3) = 0, we set each factor equal to 0: 2x - 1 = 0 → x = 1/2 and 4x - 3 = 0 → x = 3/4.",
                q2: "For the equation (x + 5)(x - 7) = 0, we set each factor equal to 0: x + 5 = 0 → x = -5 and x - 7 = 0 → x = 7.",
                q3: "For the equation (3x - 2)(x + 1) = 0, we set each factor equal to 0: 3x - 2 = 0 → x = 2/3 and x + 1 = 0 → x = -1.",
                q4: "For the equation (4x + 3)(2x - 5) = 0, we set each factor equal to 0: 4x + 3 = 0 → x = -3/4 and 2x - 5 = 0 → x = 5/2.",
                q5: "For the equation (5x - 4)(x + 3) = 0, we set each factor equal to 0: 5x - 4 = 0 → x = 4/5 and x + 3 = 0 → x = -3."
            };

            const answerElement = document.getElementById(`${question}${selectedAnswer}`);
            const correctAnswer = correctAnswers[question];

            if (selectedAnswer === correctAnswer) {
                answerElement.classList.add('correct');
            } else {
                answerElement.classList.add('incorrect');
            }

            const explanationElement = document.getElementById(`explanation${question.slice(1)}`);
            explanationElement.innerHTML = explanations[question];
        }

        function checkAnswers() {
            checkAnswer('q1', 'a');
            checkAnswer('q2', 'a');
            checkAnswer('q3', 'a');
            checkAnswer('q4', 'c');
            checkAnswer('q5', 'a');
        }

        function resetQuiz() {
            const answers = document.querySelectorAll('.answer');
            answers.forEach(answer => {
                answer.classList.remove('correct', 'incorrect');
            });
            const explanations = document.querySelectorAll('.explanation');
            explanations.forEach(explanation => {
                explanation.innerHTML = '';
            });
        }
